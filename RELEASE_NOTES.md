# Redoubt 2.1.1

## Improvements

- Renamed **"☰ Settings"** to **"☰ Menu"**.
- Added a dedicated Settings submenu to accommodate future application settings.
- Added an **opt-in** update check at launch, which connects to the GitHub API (`api.github.com`) to check for new releases. This requires an internet connection and exposes the user's public IP address to GitHub.
